Fine-Motor Skill Aplication
============

## Description
The Fine-Motor Skill Application is a website built to help toddlers practice and develop their motor skills through exercises.

## Features
The website contains three exercises:
* Clicking objects
* Dragging objects
* Drawing lines

## How to use
https://khoadinhnguyen.github.io/games_with_p5js/

## Technologies
HTML, CSS, JS (with p5.js library).
